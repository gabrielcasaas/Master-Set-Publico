# Gabriel's Master Set

Vitrine pública, somente leitura, da coleção física. O arquivo `collection.json` é uma cópia do backup exportado pelo CardDex.

## Como publicar no GitHub Pages

1. Crie um novo repositório público, por exemplo `master-set-gabriel`.
2. Copie todos os arquivos desta pasta para o repositório usando o GitHub Desktop.
3. Faça um commit e clique em **Publish repository**.
4. No GitHub, abra **Settings → Pages**, escolha a branch `main` e a pasta `/(root)`.

## Como atualizar a vitrine

1. No CardDex, clique em **Exportar**.
2. Arraste o arquivo baixado sobre `atualizar-colecao-publica.bat`.
3. No GitHub Desktop, faça commit/push da alteração em `collection.json`.

Em poucos minutos, a vitrine pública mostrará as novas cartas. Visitantes nunca conseguem editar: apenas sua conta do GitHub pode publicar atualizações.

## Contato

Em `index.html`, substitua `SEU_EMAIL_AQUI` pelo seu e-mail público. O botão abre o aplicativo de e-mail do visitante; não exige servidor nem expõe sua caixa de entrada.

## Google AdSense

O bloco de publicidade está apenas reservado. Para receber anúncios reais, você precisa criar e ter uma conta aprovada no Google AdSense, ter uma política de privacidade no site e receber o seu identificador `ca-pub-...`. Depois disso, o código fornecido pelo AdSense pode ser adicionado ao espaço reservado. Nunca coloque senha, dados bancários ou a conta Google dentro do repositório.
